# Objetivo

Criar uma aplicação web que permita a times pequenos gerenciar sprints de forma intuitiva, desde a criação do backlog até o encerramento do sprint, com dashboards de acompanhamento e assistência de inteligência artificial para otimizar o processo agil.

# Tecnologias

* Front-end
  - React.js com TypeScript
  - Tailwind CSS para estilização
  - Biblioteca de drag & drop
  - Chart.js
* Back-end
  - Node.js com Express ou Fastify
  - API REST com autenticacao JWT
* Banco de Dados
  - PostgreSQL
* Inteligência Artificial
  - API da Claude (Anthropic)
  - Claude Code / Cursor / Copilot para desenvolvimento do sistema
    
# Histórias de Usuários

1. Como usuário, quero criar uma conta e fazer login para acessar meus projetos.
2. Como usuário, quero criar um projeto e convidar membros para trabalhar em equipe.
3. Como PO, quero adicionar histórias de usuário ao backlog com título, descrição e story points para organizar o trabalho.
4. Como usuário, quero criar um sprint com data de início e fim para planejar a iteração.
5. Como usuário, quero mover histórias do backlog para o sprint durante o planning.
6. Como membro do time, quero mover tarefas entre colunas (To Do / In Progress / In Review / Done) no board Kanban.
7. Como usuário, quero ver um dashboard com o progresso do sprint atual (burndown, % concluído).
8. Como usuário, quero usar IA para gerar sugestões de histórias de usuário a partir de uma descrição do projeto.
9. Como usuário, quero encerrar um sprint e ver um resumo automático gerado por IA do que foi concluído.
